 Insider Threat Monitoring & User Behavior Analysis System

A cybersecurity project designed to monitor system logs, analyze user activities, and identify potentially suspicious behavior that may indicate insider threats or security incidents.

The system collects and analyzes log data from multiple environments, including Windows Server, Kali Linux, and Red Hat Linux, using a centralized logging approach. It provides a dashboard for monitoring security events, tracking failed login attempts, analyzing system activities, and identifying potential risks.

 Key Features

- Centralized Log Monitoring: Collects and monitors system logs from multiple machines and operating systems.
- Failed Login Detection: Tracks unsuccessful authentication attempts that may indicate suspicious access activity.
- User Activity Analysis: Monitors selected system activities, including administrative commands and "sudo" operations.
- Security Alerts: Highlights potentially suspicious events to support faster investigation and response.
- Risk Assessment: Presents security indicators and risk levels based on the implemented detection rules.
- Interactive Dashboard: Displays security statistics, event counts, host information, and visual summaries of monitored activities.
- Multi-System Monitoring: Demonstrates log monitoring across Windows and Linux environments.

 Technologies & Tools

- Python — Log analysis, data processing, and dashboard development.
- Streamlit / Flask — Dashboard and web application development, depending on the implementation.
- Visual Syslog Server — Centralized syslog collection.
- Windows Server — Windows system and security event monitoring.
- Kali Linux — Security testing and analysis in a controlled lab environment.
- Red Hat Linux — Linux log monitoring and system activity analysis.

 Project Objectives

The main objective is to demonstrate how centralized logging and user behavior analysis can help security teams detect suspicious activities, investigate security events, and improve visibility across different systems.

This project provides hands-on experience with log management, security monitoring, system administration, and the practical application of cybersecurity concepts in a multi-system environment.
